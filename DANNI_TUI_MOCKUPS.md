## DESIGN NOTES

### Typography Hierarchy
1. **Headers**: Bold, purple, larger text
2. **Body**: Regular, cream, readable size
3. **Secondary**: Smaller, gray, contextual info
4. **Code**: Monospace, highlighted, colored syntax

### Spacing Philosophy
- **Breathing room**: Generous padding around content
- **Grouping**: Related items visually clustered
- **Separation**: Clear dividers between sections
- **Balance**: Neither cramped nor sparse

### Color Application
- **Purple gradient**: Headers, active states, primary actions
- **Midnight blue**: Backgrounds, depth, sophistication
- **Rose gold**: Success, warmth, highlights
- **Cream/gray**: Text, secondary info
- **Semantic colors**: Errors (red), warnings (amber), success (green), info (blue)

### Border Styles
- **Rounded**: Friendly, modern (message bubbles, cards)
- **Square**: Technical, structured (main window, settings)
- **Double-line**: Emphasis, importance (headers, footers)
- **Subtle**: Unobtrusive dividers between sections

### Progressive Disclosure
- **Start simple**: Show essential UI first
- **Reveal gradually**: Advanced features appear as needed
- **Hide complexity**: Settings, help, extensions in overlays
- **Context-aware**: Show relevant options based on state
